# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) Introduction to SQL Queries Project**.

Structured Query Language (SQL) is one of the core technologies used by data scientists, analysts, software engineers, and researchers to work with relational databases. In this beginner-friendly project, I learned how to retrieve, filter, and organize data by writing SQL queries against the **New York City Airbnb dataset**.

Working through the project introduced me to database setup, loading data, writing SQL queries, and performing simple data analysis. Although designed as an introductory project, it provided the foundation needed for more advanced SQL topics such as joins, subqueries, window functions, and database optimization.

# Skills Demonstrated

## Database Setup

The project began by creating a relational database and loading the Airbnb dataset.

During this stage, I learned how to:

* Connect to a SQLite database
* Create database tables
* Import structured datasets
* Organize relational data
* Prepare a database for querying

Understanding how databases are organized is the first step toward effective data analysis.

---

## Loading the Dataset

Before querying data, I learned how to properly load a real-world dataset into the database.

This included:

* Importing CSV data
* Verifying successful imports
* Exploring table contents
* Understanding dataset structure

Working with a real dataset provided practical experience beyond simple SQL examples.

---

## Writing SQL Queries

The primary objective of this project was learning how to retrieve information from a relational database.

I gained experience writing queries using:

* `SELECT`
* `FROM`
* `LIMIT`

These commands form the foundation of almost every SQL query.

---

## Filtering Data

After retrieving information, I learned how to focus on specific records.

This included using:

* `WHERE`
* Comparison operators
* Logical conditions
* Text filtering

Filtering allows analysts to answer targeted questions using large datasets.

---

## Sorting Results

Organizing results makes data easier to interpret.

During this stage, I explored:

* `ORDER BY`
* Ascending order
* Descending order
* Sorting numerical and text fields

Sorting improves readability and helps identify important trends.

---

## Basic Data Analysis

Rather than simply writing SQL syntax, I used SQL to answer questions about Airbnb listings.

Examples included:

* Viewing listing information
* Filtering neighborhoods
* Exploring prices
* Examining room types
* Investigating listing availability

This demonstrated how SQL supports practical business analysis.
